# 商品咨询与保养

## 面料说明

- **纯棉**：透气吸汗、亲肤柔软，适合日常T恤、衬衫；易皱，洗涤后建议及时整理晾晒；
- **棉混纺**：加入聚酯纤维或氨纶，抗皱性和弹性更好，不易变形；
- **羊毛**：保暖性好、垂坠感强，建议干洗或冷水手洗，避免暴晒；
- **羊绒**：轻盈保暖，需使用专用洗涤剂轻柔手洗，平铺阴干；
- **真丝**：光泽柔和、亲肤，建议干洗，避免与粗糙面料摩擦；
- **聚酯纤维**：耐磨、易打理、快干，透气性相对较弱；
- **锦纶**：强度高、耐磨，常用于运动外套和羽绒服面料；
- **氨纶**：提供弹性，含量通常在 2% 至 10% 之间。

商品详情页会标注面料成分与含量，实际手感以收到商品为准。

## 洗涤与保养

1. 洗涤前查看水洗标，按标注的温度和方式清洗；
2. 深浅色衣物分开洗涤，首次洗涤建议单独清洗，避免染色；
3. 羊毛、羊绒、真丝不宜机洗和烘干，建议冷水手洗或干洗；
4. 印花、刺绣衣物反面洗涤，避免高温熨烫图案；
5. 羽绒服建议使用中性洗涤剂，低温烘干并轻拍恢复蓬松；
6. 长期存放前请洗净晾干，放入防尘袋，避免重压。

## 色差与气味

- 因拍摄灯光、显示器色域不同，实物与图片可能存在轻微色差，属于正常现象；
- 新衣服可能有轻微面料或包装气味，通风晾晒 24 至 48 小时后可消散；
- 若气味刺鼻或洗涤后仍无法消散，可申请质量问题退换。

## 尺码与版型咨询

- 商品详情页提供尺码表、模特试穿信息和版型说明；
- 修身款建议选大一码，宽松款可按正常码选择；
- 身高体重处于交界值时，结合胸围、腰围数据选择；
- 需要搭配建议时，可提供身高、体重、常用尺码，由客服推荐。

## 搭配建议

- **通勤**：衬衫 + 直筒西裤 + 乐福鞋，外搭西装或风衣；
- **休闲**：纯色T恤 + 牛仔裤 + 运动鞋，可叠加针织开衫；
- **约会**：连衣裙 + 小外套 + 单鞋，选择低饱和色系更显气质；
- **运动**：速干上衣 + 弹力裤 + 跑鞋，注意面料透气与弹性；
- **冬季**：羊毛大衣或羽绒服 + 高领针织 + 长裤，注意内搭与外搭的厚度匹配。

## 常见问题

**问：衣服会掉色吗？**
答：深色纯棉和牛仔面料首次洗涤可能有轻微浮色，建议单独冷水洗涤。若多次洗涤后仍严重掉色，可提供照片申请质量问题处理。

**问：新衣服有味道正常吗？**
答：轻微气味通常来自面料整理剂或包装，通风晾晒后可消散。气味刺鼻且不消散的，可申请退换。

**问：羊毛大衣怎么洗？**
答：建议干洗。如自行清洗，请使用羊毛专用洗涤剂冷水轻柔手洗，平铺阴干，避免拧干和暴晒。

**问：可以帮忙搭配吗？**
答：可以。提供身高、体重、场合和偏好风格，客服可给出搭配建议与尺码推荐。

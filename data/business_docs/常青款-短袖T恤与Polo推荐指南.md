## 二、逐款说明

### 1. 云感 240g 圆领短袖（XC26SS-TS001）

- 颜色：白、黑、燕麦、雾蓝；尺码：S-XXL；男女同款。
- 面料：100% 精梳棉，240g 中厚克重，不透、不易激凸。
- 版型：合身直筒，肩线标准，衣长到胯骨附近。
- 推荐理由：最百搭的内搭款，配风衣、牛仔夹克、飞行员夹克都不臃肿。
- 搭配建议：白短袖 + 卡其风衣 + 直筒西裤；黑短袖 + 牛仔夹克 + 牛仔裤。
- 洗护：30°C 以下反面洗涤，首次单独洗，不可漂白；纯棉首次水洗缩率通常在 3% 以内。

### 2. 重磅 300g 落肩短袖（XC26SS-TS002）

- 颜色：白、炭灰、军绿；尺码：M-XXL；男女同款。
- 面料：100% 棉，300g 重磅，面料挺括，单穿有轮廓感。
- 版型：落肩宽松，袖口和衣身偏宽，衣长略长。
- 推荐理由：适合单穿和街头风格；作为夹克内搭时建议确认夹克胸围余量。
- 搭配建议：白重磅短袖 + 飞行员夹克 + 直筒牛仔；军绿短袖 + 工装夹克 + 工装裤。
- 洗护：反面冷水洗，不可高温烘干；重磅棉首次洗涤可能有 2-3% 缩率，属正常范围。
- 注意：落肩版型肩宽数据偏大，按胸围选码更准确。

### 3. 冰感速干短袖（XC26SS-TS003）

- 颜色：黑、白、湖蓝；尺码：S-XXL；男女同款。
- 面料：聚酯纤维 88%、氨纶 12%，吸湿速干，带轻微凉感。
- 版型：修身运动版型，肩袖贴合，弹力较大。
- 推荐理由：适合跑步、骑行、旅行和高温天气；也可作为运动夹克内搭。
- 搭配建议：速干短袖 + 夜跑运动夹克 + 运动裤；白色款可搭配工装夹克日常穿。
- 洗护：冷水洗涤，不可使用柔顺剂，不可高温烘干；避免与魔术贴、粗糙面料摩擦。
- 注意：速干面料不建议高温熨烫，以免损伤弹力纤维。

### 4. 珠地 Polo（XC26SS-PL001）

- 颜色：藏青、白、墨绿、浅灰；尺码：S-XXL；男女同款。
- 面料：棉 95%、氨纶 5%，珠地网眼结构，透气且有挺括感。
- 版型：合身翻领，袖口收边，衣长适中。
- 推荐理由：比圆领短袖更适合通勤和见客户；外搭风衣或双面呢不显随意。
- 搭配建议：藏青 Polo + 卡其风衣 + 直筒西裤；白色 Polo + 双面呢 + 半裙。
- 洗护：30°C 轻柔洗涤，领口轻揉，不可用力拧干；悬挂或平铺晾干，低温熨烫领口。
- 注意：Polo 领口变形多与机洗拉扯有关，建议装入洗衣袋。

### 5. 星轨印花短袖（XC26SS-TS004）

- 颜色：白、黑；尺码：S-XL；男女同款。
- 面料：100% 棉，220g，印花位于胸前。
- 版型：常规直筒，合身略宽松。
- 推荐理由：适合周末、旅行和拍照；作为纯色外套的内搭能增加层次。
- 搭配建议：印花短袖 + 牛仔夹克 + 直筒牛仔裤；黑色款 + 工装外套 + 卡其裤。
- 洗护：反面洗涤，不可直接熨烫印花，不可漂白；建议与深色衣物分开洗。
- 注意：印花款为限量补货，售罄后补货周期较长。

## 三、克重和面料怎么选

- 180-220g：轻薄透气，适合高温天气和运动内搭；白色可能略透。
- 240g：中厚百搭，不透不闷，最适合秋冬内搭。
- 300g：重磅挺括，适合单穿；叠穿时要注意外层胸围余量。
- 精梳棉：手感细腻、不易起球，适合贴身穿着。
- 普通纯棉：性价比高，洗后可能有轻微缩水和褶皱。
- 速干聚酯：排汗快、易干，适合运动；不建议高温熨烫。
- 珠地棉：透气、有肌理感，适合 Polo 和通勤场景。

## 四、秋冬叠穿建议

- 风衣内搭：选 240g 圆领或珠地 Polo，领口简洁，不抢外套领型。
- 牛仔夹克内搭：选 240g 或 300g 短袖，白色最稳，黑色更利落。
- 飞行员夹克内搭：选 300g 重磅短袖，领口和袖口露出一点更有层次。
- 双面呢内搭：选珠地 Polo 或半高领针织；圆领短袖适合室内脱外套后单穿。
- 轻羽绒内搭：选 240g 短袖或薄针织，避免过厚导致肩部紧绷。
- 南方暖冬：短袖 + 夹克即可；早晚加一条围巾。

## 五、缩水、变形和起球

- 纯棉短袖首次水洗缩率通常在 3% 以内；超过 3% 且影响穿着，可在 30 天内申请质量售后。
- 白色棉T恤不要与深色牛仔混洗，避免染色；首次洗涤建议单独洗。
- 印花短袖反面洗、反面晾，不要直接熨烫图案。
- 速干短袖不可使用柔顺剂，也不可高温烘干，否则会影响排汗性能。
- 棉T恤领口变形多与悬挂晾晒和机洗拉扯有关，建议平铺或对折悬挂。
- 轻微起球可用毛球修剪器处理；短袖非摩擦部位明显起球可在 30 天内申请质检。

## 六、常见问题

- 问：秋冬买短袖有什么用？答：作为风衣、夹克、羽绒服内搭，室内脱外套后也体面；南方和空调房可单穿。
- 问：240g 和 300g 差多少？答：240g 更薄更适合内搭，300g 更厚更挺括，适合单穿。
- 问：白色短袖会透吗？答：240g 白色正常穿着不透；如果介意，可选燕麦色或雾蓝色。
- 问：纯棉短袖洗后缩水正常吗？答：3% 以内属正常；超过 3% 可申请质量售后。
- 问：速干短袖可以日常穿吗？答：可以，搭配牛仔裤或西裤即可；运动场景更合适。
- 问：175cm、70kg 男生短袖选什么码？答：云感短袖建议 L，喜欢宽松可选 XL；重磅短袖建议 L。

## 阅读顺序建议

- **第一次接触项目**：学习指南 → 系统架构与数据流 → 请求全链路详解 → 开发指南 → 接口文档。
- **准备上线**：部署文档 → 配置参数手册 → 安全与权限说明 → 运维与故障排查。
- **排查效果问题**：评估指标 → 请求全链路详解（过滤/缺口分支）→ 问题与解决方案 → 运维与故障排查。
- **排查性能问题**：测试指标（性能章节）→ 运维与故障排查（慢响应）→ 配置参数手册（重排序参数）。

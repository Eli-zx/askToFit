# 演示前检查清单（多人线上演示：注册/浏览 200 人，同时提问按 20 并发）

> 演示当天按顺序勾选；任一项不通过，先修复再开始。
> 目标：100 位客户自行注册、登录、提问不失败；管理员始终优先；页面亮/暗都像高端品牌。

## 1. 配置档

- [ ] 以 `deploy/demo.env.example` 为底稿生成演示 `.env`，替换所有 `replace-me`
- [ ] `ADMIN_USERNAMES` 已填写演示管理员账号
- [ ] 确认关键容量项：`MAX_CONCURRENT_LLM=16`、`LLM_ADMIN_SLOTS=4`、
      `DB_POOL_SIZE=20`、`DB_MAX_OVERFLOW=40`、`RATE_LIMIT_REGISTER_REQUESTS=500`、
      `RATE_LIMIT_LOGIN_REQUESTS=30`
- [ ] 确认缓存：`ANSWER_CACHE_TTL=43200`、`RETRIEVAL_CACHE_TTL=43200`、
      `CACHE_TTL_JITTER=0.02`、`RETRIEVAL_SINGLEFLIGHT=true`
- [ ] 确认 `MODEL_WARMUP_INTERVAL_SECONDS=0`（只关闭空闲保活，启动预热仍保留）
- [ ] MySQL `max_connections ≥ 100`（应用池 20+40，留有余量）

```bash
uv run python -c "from config import Config; print(Config.max_concurrent_llm, Config.llm_admin_slots, Config.db_pool_size, Config.rate_limit_register_requests)"
```
